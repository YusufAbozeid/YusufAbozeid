### 🧬 The Dual-Core Engineering Architecture

> *Most engineers either write firmware for silicon or train models in Jupyter. I architect the full spectrum — embedding neural networks directly onto microcontrollers, optimizing distributed mesh protocols, and deploying production-grade zero-hallucination RAG pipelines.*

<table>
  <tr>
    <td width="50%" valign="top">
      <h4 align="center">⚡ CORE 0: BARE SILICON &amp; EDGE IOT</h4>
      <ul>
        <li><b>Microcontrollers:</b> ESP32 (Xtensa Dual-Core 240MHz), Bare-Metal C/C++, FreeRTOS.</li>
        <li><b>Mesh Networking:</b> ESP-NOW peer-to-peer mesh protocol achieving <b>sub-3ms latency</b> with zero internet dependency.</li>
        <li><b>Embedded Neural Cortex:</b> On-chip predictive thermal modeling (dT/dt), dynamic peak-shaving for EV chargers, and sensor anomaly heuristics.</li>
        <li><b>Power &amp; SCADA:</b> ADC current sensor calibration, Solar Inverter ATS transfer switching, and embedded real-time web telemetry.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4 align="center">🧠 CORE 1: COGNITIVE AI &amp; TRANSFORMERS</h4>
      <ul>
        <li><b>Transformers:</b> Fine-tuning <b>DeBERTa-v3</b>, <b>AraBERT</b>, and cross-encoders with custom weight decay &amp; dropout regularization.</li>
        <li><b>RAG Architectures:</b> Dual-engine hybrid retrieval (Dense ChromaDB + Okapi BM25 via Reciprocal Rank Fusion k=60).</li>
        <li><b>Safety Guardrails:</b> 5-layer verification workflows with sub-3ms drug refusal &amp; deterministic citation enforcement.</li>
        <li><b>Production Stack:</b> FastAPI asynchronous microservices, Next.js 15 TypeScript frontends, and Sentry distributed tracing.</li>
      </ul>
    </td>
